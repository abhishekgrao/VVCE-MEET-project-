# How to run VVCE Meet locally

To start the website on your local machine, follow these steps:

1. **Open your terminal** (Command Prompt or PowerShell) in the project directory:
   `c:\Users\Admin\Desktop\PERSONAL PROJECT\VVCE meet project\vvce-meet`

2. **Install dependencies** (only needed the first time or if you update the project):
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   npm start
   ```

4. **Open your browser** and go to:
   [http://localhost:3000](http://localhost:3000)

---
**Note:** If you want to run it in development mode (with auto-reload when you change files), use:
```bash
npm run start-dev
```
